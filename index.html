backup-david

Personal encrypted backup utility.

What this application does

backup-david is a private, single-user application that creates encrypted backups of the owner's own project folders and stores them in the owner's own Google Drive account.

It is built on the open-source tools restic (encryption and deduplication) and rclone (transfer to Google Drive). It runs as a scheduled task on the owner's computer.

How it uses Google Drive

  • It requests the drive.file scope only.
  • That scope limits access strictly to files the application itself creates.
  • It cannot read, modify, or delete any other file in the user's Google Drive.
  • All data is encrypted on the user's computer before upload. The stored backup is opaque: file names and contents are not readable by anyone without the owner's encryption password.

Availability

This application is not offered as a public service and has no users other than its owner. It is published here only to satisfy Google's OAuth configuration requirements.
