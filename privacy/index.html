Privacy Policy

backup-david — last updated 28 September 2026

Scope

backup-david is a single-user application operated by its owner on their own computer, for the sole purpose of backing up their own files to their own Google Drive account. It has no other users.

What data is accessed

The application requests the Google Drive drive.file scope. This scope grants access only to files the application itself creates. The application does not read, modify, or delete any pre-existing content in the user's Google Drive.

How data is handled

  • Backup data is encrypted on the user's own computer, before it is uploaded.
  • Encryption keys never leave the user's computer and are not transmitted to any third party.
  • Uploaded data is stored solely in the account owner's own Google Drive.
  • No data is transmitted to any server operated by the application's author.

What is not done with data

The application does not sell, share, transfer, or disclose user data to any third party. It does not use data for advertising, profiling, analytics, or training of machine-learning models. There is no telemetry of any kind.

Retention and deletion

Backups are retained in the owner's Google Drive according to a retention policy the owner configures, and are deleted automatically when they fall outside it. The owner can delete all stored data at any time by removing the backup folder from their Google Drive, and can revoke the application's access at any time at myaccount.google.com/permissions.

Changes

Any change to this policy will be published on this page.
